# Architecture decision records

One file per decision that had a real alternative. If there was only one sensible option,
it is not a decision and it does not belong here.

Format: [MADR](https://adr.github.io/madr/), lightly trimmed. Numbered sequentially,
never renumbered, never deleted. A decision that turns out to be wrong gets a new record
that supersedes it — the old one stays, because the reasoning that led to a mistake is
worth more than the absence of the mistake.
